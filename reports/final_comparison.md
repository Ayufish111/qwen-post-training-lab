# 组 1：SFT 最终对比报告

> 状态：P0 已闭合
> 更新时间：2026-08-08
> 评测后端：Hugging Face Transformers

## 1. 冻结评测协议

五组实验使用同一份 `facebook/Multi-IF` 中文数据、同一官方规则代码和同一生成协议：

```text
rows: 454
turns per row: 3
max_new_tokens: 512
do_sample: false
enable_thinking: false
compute_dtype: bfloat16
```

输入数据 SHA256：

```text
ce43827ef4b43c6fde34038180ed2deb4795a7aef331e187de5fd0a5da15601c
```

主表指标为官方 `official_overall_average`。它是 strict/loose 与 prompt/instruction
四项结果的平均值，不等同于自然语言质量评分。

## 3. 控制变量结论

| 比较 | 主要差异 | turn 1 差值 | turn 2 差值 | turn 3 差值 | 三轮均值差 | 结论 |
|---|---|---:|---:|---:|---:|---|
| S2 - S1 | LoRA target | +0.032106 | +0.007716 | +0.004179 | +0.014667 | 当前配置下 all-linear 胜出 |
| S2 - S3 | clean vs raw 2k | +0.047743 | +0.041419 | +0.032248 | +0.040470 | 相同规模与预算下 clean 胜出 |
| S4 - S2 | full clean 10k、1158 steps vs 精选 clean 2k、200 steps | -0.052289 | -0.024119 | -0.006387 | -0.027598 | S4 未提升，但不是纯数据规模消融 |
| S4 - B0 | 完整 SFT vs Base | +0.044632 | +0.119704 | +0.068598 | +0.077645 | SFT 三轮均优于 Base |

S4 的结果是负结果，不能改写成“更多干净数据一定更好”。但 S4-S2 同时改变了数据规模、数据质量
分布和训练预算：S2 使用质量分更高的精选 2k 并训练 200 steps；S4 使用完整 10k 并训练 1158
steps。因此该比较只能说明当前 S4 完整方案没有超过 S2，不能单独归因于数据规模。

## 4. 完整性与可比性审计

- B0/S1/S2/S3/S4 各有 454 行、454 个唯一 ID，无重复 ID。
- 五组 ID 集合完全一致。
- 每行均有 3 个按 `1, 2, 3` 排列的 turn，共 1362 次生成。
- 五组均无空回答。
- 五份 summary 的数据 SHA256 与冻结值一致。
- 五份 summary 的 `max_new_tokens`、采样开关、thinking 开关和计算 dtype 一致。

因此，这五组可以用于同协议下的相对比较。

## 5. 长度上限与重复风险

| ID | 达到 512 generated tokens | 比例 |
|---|---:|---:|
| B0 | 946 / 1362 | 69.46% |
| S1 | 1361 / 1362 | 99.93% |
| S2 | 1362 / 1362 | 100.00% |
| S3 | 1362 / 1362 | 100.00% |
| S4 | 1362 / 1362 | 100.00% |

S4 的所有 turn 都触及生成上限，抽样输出中也可见重复。S2/S3 同样全部触顶，S1 几乎全部触顶。
这说明组 1 存在严重的长度截断或重复风险。

由于所有实验在该问题被发现前已经用同一冻结协议跑完，当前不单独修改 S4 的生成参数，也不重跑
B0-S4。这样保留了组内可比性，但对外必须限制主张：本表反映固定 checker 下的相对指令约束表现，
不能证明自然对话质量、简洁性或无重复性。

## 6. 结论边界与门禁

可以声称：

- 完成了 B0-S4 的同协议、可审计 SFT 消融。
- 当前配置下 all-linear 优于 attention-only。
- 相同 2k 规模与训练预算下，clean 数据优于 raw 数据。
- S4 相比 Base 有提升，但当前 full-clean-10k/1158-step 方案并未优于精选 clean-2k/200-step S2。

不能声称：

- 数据越多效果必然越好。
- 上述结果具有跨模型、跨 benchmark 或统计显著的通用性。
- 组 1 输出具有良好的自然对话质量或长度控制。
- 单凭这些结果可以确定 S4 低于 S2 的因果机制。

P0/G-S4 已通过，组 1 正式闭合。下一阶段可以进入组 2 的实现前冻结与数据边界工作，但必须先固定
Multi-IF dev/test 切分，且不得把 Multi-IF 原题用于 T1 或 RLVR 训练。
